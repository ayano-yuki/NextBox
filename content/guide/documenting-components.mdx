# ドキュメントの書き方

このセットアップでは、1ページの中に次の3つを並べるのを基本形にしています。

1. 何をする関数・コンポーネントなのか
2. 実際の見た目や挙動
3. 対象ファイルの全文

## おすすめの置き方

- ソース: `src/components/...`
- ドキュメント: `content/components/...`

たとえば `src/components/examples/SampleCounter.jsx` を解説する MDX を `content/components/examples/sample-counter.mdx` に置くと、URL は `/components/examples/sample-counter` になります。

各フォルダの見出しは `_meta.js` ではなく `index.mdx` の `title` で持たせます。

## MDX の基本例

```mdx
import { MyComponent } from '../../src/components/MyComponent'

# MyComponent

ここに意図や使いどころを書きます。

<Preview title="Live Preview">
  <MyComponent />
</Preview>

<SourceFile path="src/components/MyComponent.jsx" />
```

フォルダのトップも出したい場合は、同じ階層に `index.mdx` を置きます。

```mdx
---
title: Components
asIndexPage: true
---
```

## 関数の解説

見た目のない関数なら、`Preview` は省略して `SourceFile` と解説本文だけでも十分です。

例:

```mdx
# formatPrice

金額の表示用フォーマッタです。

<SourceFile path="src/lib/formatPrice.js" />
```
