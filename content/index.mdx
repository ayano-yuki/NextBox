# next-lab Docs

Next.js / React 製の関数やコンポーネントを、Nextra で整理して解説するための土台を用意しました。

## この構成でできること

- MDX ページ上でコンポーネントをそのまま描画して、見た目や振る舞いを確認する
- `SourceFile` コンポーネントで、対象ファイルの全文をそのまま載せる
- `content` フォルダの構造に合わせて自動でルーティングする
- `pnpm build` 時に `pagefind` で検索インデックスを生成する
